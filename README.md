# doc-catalog-qc

a Technical Document Catalog and QC System. It’s a small version of what the Information and Data Resources Center does. Documents come in, you catalog their metadata, check quality, store them, and pull them back out with searches and reports. You can finish it this weekend and talk about it Tuesday and Thursday.

Why this project works

It covers almost every duty in the posting: capturing and validating metadata, QC checks, finding discrepancies, storing and retrieving records, writing procedures and checklists, and reporting. It also gives you fresh answers to “what databases have you used,” “how would you check data quality,” and “what have you done to prepare.”
